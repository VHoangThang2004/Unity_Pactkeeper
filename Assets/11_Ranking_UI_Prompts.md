## Hướng dẫn import vào Unity

### 1. Scene Background
- Import vào `Assets/Sprites/Ranking/`
- Texture Type = Sprite (2D and UI)
- Filter Mode = Point (no filter)
- Gán vào scene `11_Ranking` → Canvas → Background (Image)

### 2. Rank Badge Sprites (7 badges)
- Import 7 files vào `Assets/Sprites/Ranking/Badges/`
- Đặt tên: `RankBadge_0_TapSu.png`, `RankBadge_1_LaoLuyen.png`, ..., `RankBadge_6_ThongNhatThienHa.png`
- Texture Type = Sprite (2D and UI)
- Filter Mode = Point (no filter)
- Compression = None (giữ chi tiết)

**Gán vào RankingManager:**
- Chọn GameObject `RankingManager` trong scene
- Inspector → **Rank Badge Sprites (Size = 7)**
  - Element 0 = RankBadge_0_TapSu
  - Element 1 = RankBadge_1_LaoLuyen
  - Element 2 = RankBadge_2_ThuLinh
  - Element 3 = RankBadge_3_Pactkeeper
  - Element 4 = RankBadge_4_ThuLinhTaiBa
  - Element 5 = RankBadge_5_ThongLinhKietXuat
  - Element 6 = RankBadge_6_ThongNhatThienHa

### 3. Score Frame Panel
- Import vào `Assets/Sprites/Ranking/`
- Texture Type = Sprite (2D and UI)
- Filter Mode = Point (no filter)
- **Sprite Editor:**
  - Border: set left/right/top/bottom borders để 9-slice scaling hoạt động (nếu cần)
  - Apply
- Gán vào `PlayerDetailPanel → ScoreBackground` (Image component)
- Image Type = Sliced (nếu dùng 9-slice) hoặc Simple

## Tips cho AI Image Generation

1. **Consistency:** Generate tất cả 7 rank badges trong cùng một session để giữ style nhất quán
2. **Resolution:** Request 256×256 cho badges để có thể downscale xuống 128×128 mà vẫn giữ chi tiết
3. **Transparent background:** Nhấn mạnh "transparent background, PNG format" trong prompt
4. **Pixel art keywords:** Luôn bao gồm "pixel art", "32x32 tile aesthetic", "2D sprite"
5. **Iteration:** Nếu badge nào không đẹp, có thể regenerate riêng badge đó với prompt cụ thể hơn

## Alternative: Tạo badges bằng tool khác

Nếu AI image generator không tạo được pixel art đủ tốt:
- **Aseprite** (paid) hoặc **Piskel** (free online) — vẽ tay pixel art
- **Midjourney/DALL-E** → post-process qua filter "pixelate" trong Photoshop/GIMP
- **Commission pixel artist** — thuê artist trên itch.io, Fiverr với brief này
